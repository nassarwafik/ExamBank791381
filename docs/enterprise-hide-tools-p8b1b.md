## 1. القاعدة

القاعدة نفسها التي طُبّقت في P8-B1a:
- **عرض فقط:** الخادم ما زال يرفض كل إجراء بـ `403 CAPABILITY_DENIED`.
- **لا معلومات صلاحيات، أو المالك لا يطبّق:** كل الأدوات، كما كانت.
- **تعذّر تحميل الصلاحيات:** لا أداة.
- **أسماء الصلاحيات** من خريطة مسارات الخادم (`route-capabilities.js`).

## 2. ما تغيّر

### بنك الامتحانات

**عيب أُصلح (fail-first):** المعلم الذي يملك عرض البنك دون الباني (حزمة «التعلّم + الواجبات الجاهزة») كان يرى «تعذر تحميل الامتحانات المحفوظة» عند كل دخول. السبب أن الصفحة كانت تقرأ `/api/saved-exams` دائمًا، وهي قراءة من الباني.

| الأداة | الصلاحية |
|---|---|
| قراءة الامتحانات المحفوظة، وقسمها، وعددها في النظرة العامة | `examBuilder.exam.edit` |
| حذف امتحان محفوظ | `examBuilder.exam.save` |
| «إنشاء امتحان جديد»، «فتح نسخة في الباني» | `examBuilder.exam.edit` أو `examBuilder.exam.create` |
| «إضافة سؤال» (وفي الحالة الفارغة) | `examBank.question.create` |
| «تعديل» و«حذف» سؤال، و«تعديل» من المعاينة | `examBank.question.edit` |
| «استيراد أسئلة» | `examBank.import.use` |
| قسم «المكتبة الرسمية» | `examLibrary.item.view` |

### الرسائل

| الأداة | الصلاحية |
|---|---|
| كاتب الرسالة المباشرة | `messages.direct.send` |
| كاتب إعلان الصف | `messages.announcement.send` |
| تعديل رسالة وحذفها | إحداهما (قاعدة المسار نفسها) |

- المحادثة تبقى للقراءة دائمًا.
- حين لا يُعرض الكاتب تظهر الملاحظة «الإرسال غير مفعّل لحسابك. الرسائل متاحة للقراءة فقط.»

### الألعاب (قرار المالك §19.30)
- «إنشاء تحدٍّ» يفتح تأليف التحدي، وكل طلباته تحتاج `games.challenge.create`.
- المعلم الذي يملك تشغيل الألعاب فقط (`games.session.run`، كحزمة «التعلّم + الواجبات الجاهزة») يرى بطاقة اللعبة دون الزر.
- **الحزمة نفسها لم تتغيّر.**

### متابعة المشاريع

كل كتابة في `/api/project-tracker` تحتاج `projects.tracker.manage`. دونها تصبح المساحة للقراءة فقط، كالصف المؤرشف:
- لا يُعرض قسما «التقييم الجماعي» و«إعداد المراحل»؛
- ملف الطالب بلا مفتاح الاعتماد وبلا شريط الحفظ؛
- شارة «مؤرشف» تبقى للأرشفة وحدها.

### لوحة القراءة في الصف («قراءة صفوفي»)
- «إدارة النشر» و«إضافة إلى الصف» هما `setLearningCourseModules`، وتحتاجان `learning.module.release`.
- تقرير القراءة يبقى.

### لوحة المتابعة
قسم التحليل بالذكاء الاصطناعي (`/api/teacher-analytics-ai`) يحتاج `reports.ai.use`. دونها لا يُعرض القسم ولا يُرسل أي طلب.
