| البند | القيمة |
|---|---|
| المرحلة | P6-E: إضافة امتحان جديد إلى المكتبة من لوحة المالك عبر استيراد ملف JSON، ثم اختيار من يراه |
| Baseline | `origin/main` = `711733c4` (#613) |
| الفرع | `claude/quirky-meitner-cu5ppl` |
| يبني على | P6-D (`docs/enterprise-teacher-exam-banks-p6d.md`)، الاستيراد المنظّم (`docs/STRUCTURED_EXAM_IMPORT.md`)، سلطة الاعتماد المشتركة 14A |
| طلب المالك | «لا اريد محرر فقط اضافة امتحان جديد للبنك عن طريق استيراد الامتحان … الاستيراد كملف json وبعد ان يمر مراحل الاعداد ويمر النشر انا اقوم باختيار لمن لديه السلطة رؤية التدريب او الامتحان» |

## 1. ما طلبه المالك

- **لا محرر.** فقط إضافة امتحان جديد إلى «بنك الامتحانات» باستيراد ملف JSON (الصيغة الجاهزة للاستيراد المنظّم).
- يمر الامتحان **بمراحل الإعداد** ثم **النشر**.
- بعد النشر **يختار المالك من يرى** الامتحان أو التدريب.

قبل P6-E كانت الامتحانات تُضاف إلى المكتبة عبر PR في المستودع فقط (P6-D §4).

## 2. التصميم

**في اللوحة (`#/owner/exams`):** زر «استيراد امتحان» يفتح لوحة بالمراحل:

```
اختيار الملف → فحص الأخطاء → الإصلاح الآمن → الفحص النهائي → النشر → تحديد الجمهور
```

| المرحلة | ما يحدث |
|---|---|
| اختيار الملف | ملف `.json` فقط. يُقرأ في المتصفح بنفس محلّل الاستيراد المنظّم (`parseStructuredExamJson`)، ولا يُرسَل شيء |
| فحص الأخطاء | نفس `validateStructuredExam` ومجموعات الأخطاء في معالج المعلم. القرار الوحيد المطلوب: قاعدة تصحيح القسم إن غابت عن الملف (لا تُخمَّن) |
| الإصلاح الآمن | نفس `repairStructuredExamSafely`: بنيوي فقط، لا يغيّر أي إجابة أو علامة |
| الفحص النهائي | نفس سلطة الاعتماد `evaluateExamFinalization`. **ما يمنع النشر يمنعه:** لا محرر، فيُصلَح الملف ويُستورد من جديد |
| النشر | العنوان، النوع (امتحان / تدريب)، التصنيف، وصف اختياري. يُرسَل الامتحان المُعدّ **مرة واحدة** (ويُعاد كما هو بعد التحقق الثاني) |
| تحديد الجمهور | محرر الجمهور نفسه الذي في الجدول (نُقل دون تغيير إلى `OwnerAudienceEditor.tsx`). «إلغاء» يترك الامتحان «لم يُحدَّد بعد» |

صف الامتحان المستورد في الجدول يحمل وسم «مستورد» (و«· تدريب» للتدريب). لوحة الاستيراد تُحمَّل كسولة: لا تدخل حزمة اللوحة إلا عند فتحها.

**الخادم: `POST /api/owner-library/import`** (جلسة المالك، تحقق ثانٍ حديث، يُسجَّل في تدقيق المالك قبل حدوثه):

| الشرط | الرفض |
|---|---|
| امتحان منظّم (`sections`، بلا `questions` علوية) | `400 EXAM_INVALID` |
| ≤ 10 ميغابايت | `413 EXAM_TOO_LARGE` |
| عنوان، تصنيف (`[a-z0-9-]`)، نوع `exam` أو `training` | `400 TITLE_REQUIRED / CATEGORY_INVALID / ACTIVITY_TYPE_INVALID` |
| كل `dataUrl` صورة نقطية مضمّنة (PNG/JPEG/WEBP/GIF) — لا رابط ولا SVG | `400 IMAGE_UNSAFE` |
| **الخادم يقرر الجاهزية:** `evaluateServerFinalization` (البناء المشترك نفسه للباني والحوكمة) بلا أي مانع | `422 EXAM_NOT_READY` (أعداد فقط، بلا محتوى) |
| ليس الامتحان نفسه مرتين (بصمة `sections`) | `409 LIBRARY_ITEM_DUPLICATE` مع رمز الموجود |
| فهرس المستوردات مقروء ومفهوم | `503` (فشل آمن، لا يُكتب شيء) |

**التخزين (`api/src/lib/exam-library-imported.js`):**

| المستند | الدور |
|---|---|
| `platform/catalog/exam-library-items/IMP-nnn.json` | العنصر بشكل المكتبة المضمّنة نفسه (بيانات + `examSnapshot` بمفاتيح الإجابة). **يُكتب مرة واحدة (create-only) ولا يتغير** |
| `platform/catalog/exam-library-imported.json` | **الفهرس، وهو المرجع الوحيد:** يُكتب بـ CAS بعد العنصر. مستند غير مُدرج غير موجود لأي قارئ؛ عنصر مُدرج مفقود أو بصمته غير بصمة الفهرس = `503` |

الرموز `IMP-001`، `IMP-002`… لا تتقاطع مع المكتبة المضمّنة. رمز يحمله مستند يتيم (كتابة فهرس فشلت سابقًا) يُتخطّى إلى التالي، وتسجّل المحاولة في التدقيق «لم تُنفَّذ».

**القراءة:** المسارات نفسها (`/api/exam-library`، الإسناد بالمرجع `libraryRef`، `/api/owner-library`) ترى مكتبة واحدة: المضمّنة ثم المستوردة. العنصر المضمّن لا يلمس التخزين أبدًا. العنصر المستورد ثابت فيُقرأ مرة لكل عملية؛ الفهرس يُقرأ في كل طلب.

**من يرى الامتحان المستورد — أشد من P6-D عمدًا:** الامتحان المستورد **يتبع جمهوره لكل جلسة معلم**، حتى قبل التطبيق (legacy / observe) وللهويات السابقة للوحة، حيث تبقى المكتبة المضمّنة كاملة كما هي. لم يكن عند أحد، فلا يخسر أحد شيئًا، و«لم يُحدَّد بعد» تعني حقًا أن لا أحد يراه. هوية بلا حساب ترى المستورد «لكل المعلمين» فقط. سجل جمهور لا يُقرأ = `503` للمستورد فقط (`importedLibraryFilter` في `library-access.js`).

**نسخة المعلم في الباني:** «فتح نسخة في الباني» لامتحان مستورد (منظّم) تفتح نسخة جديدة كمسودة في الباني المنظّم (رمز جديد). قبل P6-E كانت لا تفعل شيئًا لأن المعالج كان يقرأ `questions[]` المسطّحة فقط.

**ما لا يتغير:** المكتبة المضمّنة وجمهورها وقاعدة الإطلاق؛ الواجبات المنشورة (الواجب يحمل نسخته)؛ التصحيح (الإسناد بالمرجع يبني الواجب من نسخة الخادم بمفاتيحها كما في P6-C)؛ تدريب الطالب الذاتي (يتبع سجل المقررات، والمستورد ليس فيه).

## 3. الأدلة

**Fail-first:** الميزة جديدة، فلا ينطبق إلا على نسخ امتحان منظّم إلى الباني: `src/AppLibraryCopy.p6e.test.tsx` شُغّل على `App.tsx` من `711733c4` ففشل بـ `Unable to find role="dialog"`، ونجح على الرأس.

**الاختبارات:**

| الملف | ما يغطيه |
|---|---|
| `api/tests/owner-library-import-p6e.test.js` | النشر «لم يُحدَّد بعد» ثم الجمهور ثم القائمة والفتح والإسناد؛ التدقيق قبل الحدوث؛ IMP-002 وتغيّر الـ ETag؛ الرفض دون كتابة (التحقق الثاني، عدم الجاهزية، الصور، الشكل، التكرار، رمز المعلم)؛ الفهرس مرجعًا والفشل الآمن؛ تخطّي الرمز اليتيم؛ المستورد يتبع جمهوره قبل التطبيق وللهويات السابقة؛ سجل جمهور لا يُقرأ |
| `src/owner/OwnerLibrary.p6e.test.tsx` | المراحل كلها، النشر مرة واحدة ثم إعادته كما هو بعد التحقق الثاني، الجمهور في الخطوة الأخيرة؛ مانع متبقٍ لا يُنشر ولا يُرسل شيء؛ JSON فقط؛ وسم «مستورد» والإلغاء |
| `src/AppLibraryCopy.p6e.test.tsx` | نسخ امتحان منظّم من المكتبة إلى الباني المنظّم |

**Mutation:** `node scripts/mutate-p6e.mjs` (النتيجة في تقرير الـ PR).

**اختبار قائم عُدِّل (تغيير مقصود لا تخفيف):** `api/tests/exam-library-l7.test.js` — الفهرس يُقرأ مع كل قائمة، فأُعطي اعتمادُ الاختبار حاويةً فارغة في الذاكرة. لم يتغير أي توقّع.

## 4. القيود

- **لا تعديل ولا حذف** لامتحان مستورد. امتحان جديد = استيراد جديد. لإخفائه: جمهور «معلمون محددون» بلا أحد. الحذف يحتاج خطة وموافقة المالك (AGENTS §10).
- **JSON فقط** في لوحة المالك. HTML وPDF واقتراحات الذكاء الاصطناعي تبقى في معالج المعلم (تحتاج جلسة معلم).
- مانع واحد متبقٍ يمنع النشر: الإصلاح في الملف ثم إعادة الاستيراد.
- حد الفهرس 2000 امتحان مستورد.
- **P6-F:** أُضيف مصدر ثانٍ لامتحانات البنك: امتحانات يعدّها المعلمون بالباني ويرسلونها، والنسخة المحدَّثة تحل محل السابقة (`docs/enterprise-library-submissions-p6f.md`). نُقل كود التحضير والنشر من `owner-library.js` إلى `api/src/lib/library-publish.js` دون تغيير قواعده.
