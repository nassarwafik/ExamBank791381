# Tadris+ P8-B1a — إخفاء الأدوات التي لا تسمح بها صلاحيات المعلم داخل الصفحات

| البند | القيمة |
|---|---|
| المرحلة | P8-B1a، الجزء الأول من P8-B1 (إخفاء الأدوات داخل الصفحات) |
| Baseline | `origin/main` = `e919763b` (دمج #536) |
| الفرع | `claude/blissful-shannon-9rv461-p8b1a-hide-tools` |
| المخطط | `docs/enterprise-three-tier-p0-blueprint.md` §9.1 («لا يرى المعلم أدوات لا يملك صلاحيتها»)، §19.29 |
| يبني على | P3-C (الشريط الجانبي يتشكل من الصلاحيات)، P3-B (الخادم يفرض كل صلاحية) |

## 1. القاعدة

الشريط الجانبي يخفي الصفحات التي لا يملك المعلم صلاحيتها منذ P3-C. هذه المرحلة تطبّق القاعدة نفسها على **الأزرار داخل الصفحة**.

- **عرض فقط:** الخادم ما زال يرفض كل إجراء بـ `403 CAPABILITY_DENIED`. الواجهة تتوقف عن عرض زر سيُرفض.
- **المصدر:** جواب الدخول (`access`) نفسه، بلا أي طلب إضافي. ينقله `TeacherAccessContext` (`src/shell/teacherAccessContext.ts`) من غلاف المعلم إلى الصفحات.
- **القاعدة المشتركة:** `canUse(access, capability)` و`useCan()`.

| حالة الصلاحيات | ما يُعرض |
|---|---|
| لا معلومات (API أقدم) أو المالك لا يطبّق (observe / legacy) | كل الأدوات، كما كانت |
| تطبيق (enforce) | الأداة فقط إن ملك المعلم صلاحيتها (أو إحداها، لقائمة) |
| تعذّر تحميل الصلاحيات | لا شيء (fail closed)، كما في الشريط الجانبي |

**أسماء الصلاحيات هي أسماء خريطة المسارات في الخادم** (`api/src/lib/access/route-capabilities.js`)، لا أسماء جديدة.

## 2. ما تغيّر في كل صفحة

### التقارير
- `GET /api/reports?type=filters` يعيد `available: { academic, projects }`، بالقاعدة نفسها التي ترفض التقارير.
- مركز التقارير لا يعرض:
  - «التقييمات والواجبات» دون الجزء الأكاديمي؛
  - تقارير المشاريع الخمسة دون جزء المشاريع؛
  - تصنيفًا لم يبق فيه تقرير.
- تقرير الصف وتقرير الطالب يبقيان دائمًا (الأجزاء المحجوبة تُترك منهما في الخادم منذ P7-A1).
- API أقدم بلا `available`: كل البطاقات.

### الواجبات

**عيب أُصلح (fail-first):** المعلم بحزمة «التعلّم + الواجبات الجاهزة» كان يرى رسالة رفض عند كل دخول إلى الواجبات:
- الصفحة كانت تقرأ قائمة الامتحانات المحفوظة (`/api/saved-exams`) دائمًا، وهي قراءة من الباني (`examBuilder.exam.edit`)؛
- ونافذة الإنشاء كانت تفتح على «امتحاناتي»، التي يرفضها الخادم دون `assignments.assignment.create`.

الآن:

| الأداة | الصلاحية |

| مصدر «امتحاناتي» | `assignments.assignment.create`. دونه تفتح نافذة الإنشاء على المكتبة |
| مصدر «مكتبة 791381» | `examLibrary.item.view` |
| نسخ امتحان من المكتبة إلى الباني | `examBuilder.exam.edit` أو `examBuilder.exam.create` |
| «إنشاء واجب» (الشريط والحالة الفارغة) | `assignments.assignment.create` أو `assignments.ready.assign` |
| النشر وإيقافه، المحاولات، الوقت والموعد، الأرشفة والاستعادة، سياسة التأخير | `assignments.schedule.set` |
| تعديل العنوان والتعليمات | `assignments.content.edit` |
| الحذف النهائي | `assignments.assignment.create` |
| متى يرى الطلاب نتائجهم، ونشر النتائج | `assignments.results.release` |
| إجراءات الطالب في سجل العلامات، التحديد والإجراءات الجماعية، التذكير | `assignments.schedule.set` (كل طلبات POST في `/api/assignment-results`) |
| «عرض التصحيح» / «تصحيح الآن»، وإعادة محاولة التصحيح البرمجي | `assignments.grading.grade` |

- قائمة إجراءات الواجب التي لم يبق فيها شيء لا تُعرض.
- سجل العلامات والتصدير والطباعة تبقى لكل من يفتح الصفحة (`assignments.assignment.view`).
