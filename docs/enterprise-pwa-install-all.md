# Tadris+ PWA-INSTALL-ALL — «تثبيت التطبيق» لكل أنواع الحسابات

| البند | القيمة |
|---|---|
| المرحلة | PWA-INSTALL-ALL: زر «تثبيت التطبيق» للمعلم والمالك وفي صفحتي الدخول، كما هو عند الطالب |
| Baseline | `origin/main` = `871eca17` (#617) |
| الفرع | `ccr-79612bb4-sopce0` |
| يبني على | Phase 6A (`src/pwa/installPrompt.ts`)، Phase 10C (المدخل الدائم)، UX-S1 (`useInstallEntry`) |
| طلب المالك | «كان يظهر زر تثبيت بالهاتف والحاسوب وحاليا اختفى… افحص الامر» ثم «طبعا للجميع» |

## 1. ما وُجد عند الفحص

- **الموقع قابل للتثبيت.** الموقع الحي في Chromium (حاسوب وهاتف): الـ manifest يُقرأ بلا أخطاء، الأيقونات الأربع `200 image/png`،
  الـ service worker مفعّل، و`Page.getInstallabilityErrors` يعيد قائمة فارغة. لا عطل في الخادم ولا في النشر.
- **الفجوة في الواجهة.** `initInstallPrompt` (Phase 6A) يلتقط `beforeinstallprompt` ويمنع شريط التثبيت التلقائي للمتصفح في **كل**
  الصفحات، على أن يعرض التطبيق زرّه هو. لكن الزر كان في بوابة الطالب فقط (الشريط العلوي، قائمة «المزيد» على الهاتف منذ UX-S1،
  وبطاقة الصفحة الرئيسية). المعلم والمالك وصفحتا الدخول بلا أي زر تثبيت: لا شريط من المتصفح ولا زر من التطبيق.

## 2. التغيير

السلوك واحد في كل مكان، وهو سلوك زر الطالب نفسه: إن التقط المتصفح نافذة التثبيت فُتحت عند الضغط فقط؛ وإلا يُفتح حوار الإرشاد
(خطوات iPhone / iPad، أو مسار قائمة المتصفح). لا يُفتح شيء تلقائيًا. والتطبيق المثبّت (standalone) لا يعرض الزر إطلاقًا.

| المكان | الموضع |
|---|---|
| واجهة المعلم (`TeacherAppShell.tsx`) | مجموعة «الحساب» في القائمة الجانبية، فوق «تسجيل الخروج» (الذي يبقى آخر عنصر). على الهاتف: داخل القائمة التي يفتحها «القائمة» / «المزيد»؛ اختياره يغلق القائمة ويبقى الحوار |
| لوحة المالك (`OwnerAccountMenu.tsx`) | قائمة الحساب، فوق «تسجيل الخروج». الحوار خارج القائمة فيبقى بعد إغلاقها |
| صفحة دخول المعلم / الطالب (`App.tsx`) | تحت «الدخول بالباركود»، خارج نموذج الدخول |
| صفحة دخول المالك (`OwnerApp.tsx`) | تحت «الدخول بالباركود»، خارج نموذج الدخول |

**البنية (`src/pwa/`):**

| الملف | الدور |
|---|---|
| `useInstallEntryState.ts` (جديد) | قواعد الزر وحدها، منقولة كما هي من `useInstallEntry` |
| `InstallGuidanceDialog.tsx` (جديد) | حوار الإرشاد، منقول كما هو من `useInstallEntry`؛ يُكتب مرة واحدة |
| `useInstallEntry.tsx` | زر الطالب: القواعد + الحوار مباشرة. سلوكه ومخرجاته لم تتغير (اختبارات 6A / UX-S1 القائمة لم تُمس) |
| `useDeferredInstallEntry.tsx` + `DeferredInstallGuidanceDialog.tsx` (جديدان) | القواعد نفسها، والحوار **حزمة كسولة** تُحمَّل عند أول فتح فقط |
| `InstallSignInEntry.tsx` + `install-entry.css` (جديدان) | زر صفحتي الدخول (`.eb-install-signin`) |

**لماذا الحوار كسول:** صفحة الدخول وواجهة المعلم تُحمَّلان عند الإقلاع، وحارس الحزمة (`scripts/check-bundle-budget.mjs`، 21E.1) يمنع
طبقة الحوارات المشتركة من الحزمة الأولية. أول محاولة (الحوار مباشرة) أفشلت الحارس: `index-….js (initial) contains the dialog layer`.
الحزمة الأولية بعد التغيير: 121.8 KB gzip (الحد 125).

**ما لا يتغير:** بوابة الطالب (الزر، البطاقة، مدة الإخفاء 7 أيام)؛ الـ manifest والأيقونات والـ service worker؛ التقاط
`beforeinstallprompt` ومنع الشريط التلقائي؛ الخادم والـ API والجلسات والصلاحيات والتخزين. عرض فقط: لا طلب شبكة جديد، ولا إذن إشعارات.

## 3. الأدلة

**Fail-first:** `src/pwa/installEverywhere.test.tsx` (يستورد وحدات موجودة في الأساس فقط) شُغّل على شجرة مفصولة من `871eca17`:
9 فشل / 4 نجح من 13. الفاشلة: `expected [ 'تسجيل الخروج' ] to deeply equal [ 'تثبيت التطبيق', 'تسجيل الخروج' ]` و
`Unable to find an accessible element with the role "button" and name "تثبيت التطبيق"` (المعلم، المالك، صفحتا الدخول). الأربعة
الناجحة هي حالات «مثبّت → لا زر»، وهي **تثبيت للسلوك (pin)** لا fail-first. على الرأس: 13 / 13.

| الملف | ما يغطيه |
|---|---|
| `src/pwa/installEverywhere.test.tsx` | المعلم: الموضع والترتيب، حوار الإرشاد، نافذة المتصفح عند الضغط فقط (مقبولة → يختفي الزر، مرفوضة → الحوار)، قائمة الهاتف تُغلق والحوار يبقى، المثبّت بلا زر. المالك: الموضع، الحوار يبقى بعد إغلاق القائمة، لا طلب ولا خروج، المثبّت. صفحتا الدخول: الموضع تحت «الدخول بالباركود» وخارج النموذج، الحوار، لا طلب، المثبّت |

**اختبارات قائمة عُدِّلت (تغيير مقصود لا تخفيف):** القسم 4.

**Mutation:** لا ينطبق — عرض فقط، لا يمس ثابتًا من ثوابت الأمان أو التصحيح أو التزامن أو المتانة أو الصلاحيات.

## 5. القيود

- لا يوجد زر تثبيت في صفحات الدعوة (`#/invite`) والانتقال (`#/handoff`) وموافقة الباركود (`#/qr-scan`): صفحات عابرة بمهمة واحدة.
- ظهور نافذة التثبيت الأصلية قرار المتصفح (لا يطلقها إن كان التطبيق مثبّتًا، أو بعد رفض حديث على Android)؛ حينها يعرض الزر
  حوار الإرشاد. لم يُختبر على أجهزة حقيقية؛ الدليل اختبارات الواجهة وChromium على البناء الإنتاجي.
