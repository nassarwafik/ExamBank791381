# HW-A1 · HW-A2 — المادة التعليمية «أنظمة محوسبة» (791283)

مادة مستقلة في المواد التعليمية: مكونات الحاسوب، مكونات الحاسوب الشخصي، الأمن والأمان في المختبر، ونظام التشغيل — بلغة سهلة للطلاب، مع **نماذج ثلاثية الأبعاد للقطع** تُدار باليد، و**عشرة أسئلة في نهاية كل فصل** من امتحانات البجروت السابقة.

- **HW-A1** — النشاط الجديد «نموذج ثلاثي الأبعاد لقطعة حاسوب» (`interactive-diagram / hw-part-3d / v1`).
- **HW-A2** — المادة نفسها: 4 وحدات، 41 صفحة، 8 نماذج ثلاثية الأبعاد، 40 سؤال بجروت/تدريب في نهايات الفصول.

## 4. النشاط «نموذج ثلاثي الأبعاد لقطعة حاسوب» (HW-A1)

| | |
|---|---|
| المعرّف | `interactive-diagram / hw-part-3d / v1` (`src/learning/activities/HwPart3DActivity.tsx`، جزء كود كسول خاص به) |
| ماذا يفعل | يعرض القطعة بعارض المنصة ثلاثي الأبعاد (`Interactive3DView`: تدوير بالسحب/باللمس/بالأسهم، تكبير، دوران تلقائي، أوضاع عرض)، ويختار الطالب أي جزء — على النموذج أو في القائمة تحته — فتظهر بطاقة باسمه ووظيفته بلغة بسيطة. «إعادة تعيين» تمسح الاختيار |
| البيانات | `config = { scene, hint? }`؛ `scene` هو `Interactive3DSceneSpecV1` نفسه الذي في أسئلة الامتحانات (مجسمات: صندوق، أسطوانة، شكل بيضوي …). لا WebGL، لا ملف خارجي، لا كود من المحتوى |
| القارئ الصارم | `hwPart3d.ts`: يمرّ المشهد على مدقّق المنصة الفاشل-المغلق، وكل هدف من نوع `object`، والتدوير والتكبير والاختيار مفعّلة؛ وإلا «هذا النموذج غير متوفر حاليًا» |
| الأمان | الاختيار عرض فقط: لا يُخزَّن ولا يُرسل ولا يصبح إجابة. لا مؤقّتات غير دوران العارض الاختياري (يحترم `prefers-reduced-motion`) |
| حدود العارض | العارض يرسم بترتيب العمق (SVG)، فالسطح الكبير قد يُخفي قطعة صغيرة فوقه من بعض الزوايا؛ لذلك لوحة شريحة الـ RAM مقسومة أربعة أجزاء تحت الرقائق، والنموذج ممدود أفقيًا |
| النماذج | `scripts/hw-course/parts.mjs`: الحاسوب وملحقاته، الحاسوب المحمول، اللوحة الأم (15 جزءًا)، شريحة RAM، بطاقة الشاشة (VGA / HDMI / DVI / GPU / الذاكرة)، بطاقتا الشبكة (RJ45 / الهوائي)، تبريد المعالج (المعالج / المعجون الحراري / الزعانف / المروحة)، داخل الصندوق (مزوّد الطاقة / HDD / DVD / المراوح). نماذج تعليمية **مبسّطة** — الشكل ومكان كل جزء — وليست صورًا حقيقية |

## 5. أداة التأليف

- `scripts/hw-course/uNN.mjs` — الوحدة مكتوبة مرة واحدة بأدوات `dsl.mjs` (`P`، `DEF`، `TABLE`، `TIP`، `CLAR`، `PART3D`، `MC`، `SHORT`، `MATCH`، `CLASSIFY`، `ORDER`، `QH`).
- `npm run build:hw-course` — يكتب `src/learning/content/791283/` ويحدّث أسطر المادة في `registry.ts` و `bundledModules.ts` وسجل الخادم و `catalog.ts` (بين علامتي `BEGIN/END 791283`)، ثم يبني الأجسام المخدومة وفهارس الفحص والدراسة والصفحات.
