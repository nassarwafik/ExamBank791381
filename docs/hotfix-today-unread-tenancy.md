# Hotfix — شارة الرسائل غير المقروءة في «اليوم» تعدّ طلاب المعلم فقط

| البند | القيمة |
|---|---|
| النوع | Hotfix (أمن / Tenancy)، اكتُشف أثناء تصميم P5-B3 |
| Baseline | `origin/main` = `2df07126` (دمج PR #527) |
| الفرع | `claude/blissful-shannon-9rv461-hotfix-unread-badge` |

## الخلل
صفحة «اليوم» تطلب ملخص الرسائل غير المقروءة (`teacherDirectUnread`) **دون** شرط الـ Tenancy الذي يمرره مسار الرسائل (`canSee`، Phase 21G.0). فكانت شارة المعلم تعدّ الرسائل غير المقروءة لطلاب **كل المعلمين** على المنصة.

**الأثر:**
- رقم فقط، بلا محتوى. لكنه نشاط Tenant آخر.
- والرقم خاطئ للمعلم نفسه.

## الإصلاح
`teacher-today.js` يمرر الشرط نفسه: `studentAccessible` مع Tenant المعلم. الصفوف تؤخذ من القائمة التي قرأتها الصفحة أصلًا، فلا قراءات إضافية.

## الأدلة
- **Fail-first:** `api/tests/today-unread-tenancy-hotfix.test.js` شُغِّل والملف مطابق لـ `main` `2df07126`.
  - فشل الاختباران: شارة المعلم A أظهرت **4** (كل طلاب المنصة) بدل **1**، ولم تساوِ رقم مسار الرسائل لنفس المعلم.
  - بعد الإصلاح ينجحان.
- **Mutation:** `node scripts/mutate-hotfix-unread.mjs`، قُتلت الطفرات 3/3.
- **اختبارات قائمة عُدِّلت:** لا شيء.
