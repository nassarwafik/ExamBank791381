## 1. الخلل: لعبة التحويل بلا فحص صف ولا صلاحيات

كان `game-number-conversion.js` يكتفي بجلسة الطالب. لذلك كان يلعب كل من الآتين، أثناء التطبيق:
- طالب صف **مؤرشف**؛
- طالب **بلا صف**؛
- طالب معلم «التعلّم فقط» (بلا ألعاب).

**الآن:**
- **فحص الصف:** يلعب الطالب فقط من صف **حالي موجود وغير مؤرشف**، وإلا `403 NO_ACTIVE_CLASS`. هذه قاعدة لوحة الطالب وغرفة التحدّي المباشر نفسها، وهي في كل الأوضاع.
- **صلاحيات المعلم واختيار المالك:** تحتاج اللعبة أن تكون مفتوحة لمعلم الطالب، وإلا `403 SERVICE_NOT_AVAILABLE`. هذا الشرط أثناء التطبيق فقط.
- **السجل المحفوظ لا يُمسّ.**

## 2. اختيار المالك لألعاب كل معلم (§19.25)

**سجل الألعاب على الخادم** (`api/src/lib/game-catalog.js`): لكل لعبة القدرة التي تحتاجها.

| اللعبة | القدرة |
|---|---|
| «تحدّي أنظمة العد» (`number-conversion`) | `games.catalog.view` |
| «التحدّي المباشر» (`live-challenge`) | `games.session.run` |

**اللعبة المفتوحة لمعلم** = يملك قدرتها **و** هي ضمن اختيار المالك له.
- **الاختيار:** `resources.games` في نسخة الصلاحيات. غيابه = كل الألعاب، كقاعدة المقررات والبطاقات.
- **التحقق:** معرّفات معروفة بلا تكرار (`GAME_UNKNOWN` / `GAME_DUPLICATE`)، وإعادة تحقق عند كل قراءة (فشل مغلق `503`).
- **الاختيار لا يوسّع الصلاحيات أبدًا.**

**اللعبة المفتوحة لطالب** = مفتوحة لمعلم الطالب، بقاعدة P7-B1 نفسها:
- المعلم: `student.ownerId`، ثم مالك الصف، ثم...؛
- تُطبَّق أثناء التطبيق فقط؛
- D15: حالة حساب المعلم ليست شرطًا؛
- فشل مغلق.

**ما تغيّر:**

| المكان | ما يحدث |
|---|---|
| مسارات المعلم (`game-number-conversion-preview`، `game-live-challenge`، `game-live-session`) | بعد فحص القدرة: اللعبة خارج اختيار المالك → `403 GAME_NOT_AVAILABLE` |
| مسارات الطالب (`game-number-conversion`، `game-live-session-student`) | اللعبة غير مفتوحة لمعلمه → `403 SERVICE_NOT_AVAILABLE` |
| مسارات المالك | `assign`، و`rollback` (تعيد الألعاب مع المقررات والبطاقات)، و`effective`، و`history`، وإنشاء المعلم. وكتالوج `GET /api/owner-access` يسرد الألعاب |
| جلسة المعلم (`access.games`) | الألعاب المفتوحة له أثناء التطبيق، وكل الألعاب قبله |
| جرس الطالب (`services.games`) | الألعاب المفتوحة لمعلمه |
| لوحة المالك | قسم «الألعاب المخوَّلة»: كل الألعاب، أو ألعاب محددة فقط. دون لمسه يُعاد الاختيار كما هو، والنسخ من معلم آخر ينسخ ألعابه |
| صفحتا الألعاب | تعرضان الألعاب المفتوحة فقط. إن لم تُفتح أي لعبة لطالب لا يظهر مدخل «الألعاب». جواب أقدم يعرض كل شيء كما كان |
