## 1. ما الجديد

**قسم «المدارس» في لوحة المالك** (`#/owner/schools`):
- إنشاء مدرسة باسمها، وتعديل الاسم.
- رفع شعار وتغييره وإزالته. الإزالة تطلب تأكيدًا.
- معاينة الشعار كما يظهر فعلًا أعلى الصفحة.
- جدول «المعلمون والمدارس»: اختيار مدرسة كل معلم، أو «بلا مدرسة»، ويُحفظ الاختيار فور تغييره.

**أين يظهر اسم المدرسة وشعارها:**
- **أعلى صفحة المعلم:** بجانب شعار المنصة.
- **أعلى بوابة الطالب:** مدرسة معلمه (قرار المالك §19.8).

**ما لا تفعله المدرسة:** هي **عرض فقط**. لا تمنح أي صلاحية، ولا تغيّر أي بيانات.

**بلا مدرسة:** **لا فرق إطلاقًا.** لا شارة، ولا طلب إضافي، والردود هي نفسها حرفيًا.

## 2. أي مدرسة تظهر

| الجلسة | المدرسة |
|---|---|
| معلم حسابه من لوحة المالك | مدرسة حسابه |
| أي جلسة معلم أخرى (كلمة المرور المشتركة، `BUILDER_USERS`) | لا شيء: هويات سابقة للوحة |
| طالب | مدرسة المعلم الذي يملكه. يُحدَّد المعلم بالترتيب: `ownerId` الطالب، ثم `ownerId` صفه، ثم `LEGACY_DATA_OWNER`. البيانات القديمة غير المملوكة تتبع المساحة المستوردة `t_legacy` إن وُجد حسابها |

**عند أي خطأ في القراءة:** لا يظهر شيء، ولا يُرفض الدخول أبدًا.

## 3. الشعار: الأمان

**المعالجة:** نفس مسار الصور الشخصية الآمن (`profile-image.js`)، بلا مسار أضعف:
- **الحد:** 3 ميغابايت.
- **النوع يُفحص من البايتات الحقيقية:** JPEG أو PNG أو WebP فقط. لا SVG ولا GIF، ولا يُعتمد على الامتداد.
- **فك الترميز:** تُفك الصورة كاملة؛ ملف يبدأ ببصمة صورة وليس صورة يُرفض.
- **إعادة الترميز:** إلى WebP، وتُحذف بيانات EXIF/GPS.
- **الأبعاد:** **يُحتوى داخل 512×512 دون قصّ** (`fit: "inside"`)، والشفافية تبقى.
- **الصور الشخصية لم تتغير:** ما زالت تُقصّ مربعًا كما كانت.

**التخزين:** نفس سلطة النشر (`profile-photo-store.js`):
- كل شعار ملف جديد لا يُعاد الكتابة فوقه.
- مؤشر المدرسة يُحدَّث بـ CAS (مقارنة ثم تبديل).
- القديم يُحذف بعد ذلك.

**التقديم:** `GET /api/school-logo` **يقدّم شعار مدرسة المتصل نفسه فقط**:
- لا معامل يختار مدرسة، فلا يمكن طلب شعار مدرسة أخرى.
- الترويسات: `nosniff`، و`CSP: default-src 'none'; sandbox`، و`CORP: same-origin`، و`no-referrer`، وتخزين `private` في المتصفح.
- الطلب يرسل ترويسة الجلسة. الصورة تُعرض كرابط `blob:` كالصور الشخصية، وتعليمة CSP للصفحة (`img-src 'self' data: blob:`) لم تتغير.

**معاينة المالك:** `GET /api/owner-schools/logo?schoolId=` لجلسة المالك فقط.

## 4. بلا طلبات إضافية

- **يصل حقل `school`** (`{ schoolId, name, logo: { version, updatedAt } | null }`) مع ردّين قائمين أصلًا:
  - رد تسجيل الدخول (`/api/platform-login`)؛
  - فحص الجلسة (`/api/platform-session`).
  - **ينطبق على المعلم والطالب.**
- **الشرط:** **فقط حين توجد مدرسة.**
- **الطلب الإضافي الوحيد:** صورة الشعار، وفقط حين يوجد شعار.
- **أثر ذلك على الاختبارات:**
  - اختبار «طلبات تسجيل دخول المعلم» لم يتغير.
  - اختبارات «بوابة الطالب» التي تثبّت خصائصها `{token, displayName, onLogout}` لم تتغير، لأن المدرسة تصل إلى البوابة عبر React context.
- **لوحة الطالب** (`student-dashboard`) لم تُمسّ، ولها قياسات قراءات مثبّتة.

## 5. الخادم

| المسار | ما يفعله |
|---|---|
| `GET /api/owner-schools` | المدارس مع عدد معلمي كل منها |
| `GET /api/owner-schools/logo?schoolId=` | معاينة الشعار |
| `POST create` | `{ name }`: الاسم مطلوب، يُنظَّف، وحتى 120 حرفًا |
| `POST rename` | `{ schoolId, name }` |
| `POST logo` | `{ schoolId, dataUrl }` |
| `POST remove-logo` | `{ schoolId }` |
| `POST link` | `{ accountId, schoolId \| null }`: المعلم والمدرسة يجب أن يكونا موجودين |

- **كل POST يحتاج تحققًا ثانيًا حديثًا** (step-up)، ويُسجَّل في سجل تدقيق المالك:
  - `owner.school.created`
  - `owner.school.renamed`
  - `owner.school.logo-updated`
  - `owner.school.logo-removed`
  - `owner.school.linked` (مع `from` و`to`)
- **الحذف غير موجود:** حذف مدرسة ليس في هذه المرحلة («لا حذف بيانات دون خطة وموافقة»). يمكن فك ارتباط المعلمين وإزالة الشعار.

**التخزين:**
- `platform/schools/<sch_16hex>.json`
- `platform/school-logos/<schoolId>/`
- حقل `schoolId` في حساب المعلم.
- `organizationId: "default"` (D13) لم يتغير ولم يُستخدم.

**تسجيل المسار الجديد في السجلات:**
- `school-logo.js` أُضيف إلى `EXEMPT` في سجل الصلاحيات. السبب: عرض لهوية المتصل نفسه، كـ `teacher-profile.js`.
- وصُنّف `ownSession` في سجل العزل بين المعلمين (tenancy) مع دليله.
- و`owner-schools.js` أُضيف إلى قائمة مسارات المالك في اختبار حدود P1-A. **إضافة الملف إلى هذه القائمة تُخضعه أيضًا لشرط «لا يقبل جلسة معلم».**

## 7. القيود

- **متى يظهر التغيير:** تغيير المالك للمدرسة أو الشعار يظهر للمعلم والطالب عند الدخول التالي أو إعادة تحميل الصفحة.
- **صفحات الطالب بلا شريط علوي:** صفحات الامتحان والرسائل والألعاب لها أشرطتها الخاصة ولا تعرض الشارة.
- **حذف المدرسة:** غير متاح في هذه المرحلة.
